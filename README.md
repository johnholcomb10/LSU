# Assignments from LSU

This repository contains some of the projects and programs I have created while taking courses at LSU. Explanations for what each program does are in the READMEs contained within each course's subfolders. General explanations of what assignments cover for each course:

- Intro to CS: Introduction to object-oriented programming in Java. Concepts include basic OOP organization and syntax and use of built-in functions of Java.
- Intro to CS II: Further programming in Java. Concepts build on those learned on the first class, using inheritance, polymorphism, and recursion.
- Intro to Computers: C# and Python programming for similar concepts as Intro to CS I/II. Windows Form application was created for final project.
- Numerical Methods: Python programming centered on data analysis and algebraic solutions, such as Taylor polynomials and bisections.
- Advanced Data Structures: Data storage, search, and sort algorithms. Programs focus on the use of heaps and binary search trees.
- Computer Organization and Design: Bit-level manipulation of data structures, like floats, and programming in assembly.
- Systems Programming: Basic functions of C that underlie operating systems. Programs focus on basic system calls on specific input files and sockets.
